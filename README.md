# Data Redundancy Removal System

## Overview

The Data Redundancy Removal System is a Python-based application designed to detect, validate, and remove duplicate records from datasets. The project helps improve data quality, reduce storage requirements, and maintain consistency in databases by automatically identifying redundant information.

## Features

* Duplicate data detection
* Data validation and cleaning
* Automatic redundancy removal
* Improved data consistency
* Storage optimization
* Easy-to-use command-line interface
* Modular and scalable architecture

## Technologies Used

* Python 3
* SQLite Database
* Object-Oriented Programming
* Data Validation Techniques

## How It Works

1. Load records from the database.
2. Validate data integrity.
3. Detect duplicate entries.
4. Identify redundant records.
5. Remove duplicates while preserving unique information.
6. Generate a cleaned dataset.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/Data-Redundancy-Removal-System.git
```

2. Navigate to the project directory:

```bash
cd Data-Redundancy-Removal-System
```

3. Run the application:

```bash
python app.py
```
